# De MVP a Pro — Lightning Talk (UTN)

Lightning Talk on **UI/UX** given at **UTN** (Universidad Tecnológica Nacional), walking through three iterations of the **scouting** module in [Volley Manager](https://www.volleymanager.app/) — from a tabular MVP to a dense “pro” tool for expert operators.

**Thesis:** minimalist is not always better UX. In high-pressure, real-time domains, a intentionally denser interface can be the right experience for the expert user.
