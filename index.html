Introducción · 0:00 – 3:00

El problema del tiempo real

Registrar acciones de vóley a la velocidad de un partido en vivo. Cada segundo cuenta. Cada clic importa.

Volley Manager

Plataforma de gestión deportiva usada en producción para scouting profesional de vóley.

El desafío

Un scouter debe capturar decenas de acciones por set sin perder el ritmo del partido.

La pregunta

¿Qué interfaz maximiza velocidad y precisión para un usuario experto?

La tesis central

Minimalista ≠ Mejor UX

La regla clásica del diseño dice: menos es más. Interfaz limpia, carga cognitiva baja, curva de aprendizaje suave.

Pero en entornos profesionales de alta exigencia — como el deporte en tiempo real — esa regla se rompe.

Aumentar la complejidad visual y saturar la pantalla intencionalmente puede ser el camino correcto para maximizar la velocidad del usuario experto.

FASE 1

3:00 – 6:00

MVP Tabular

  • Solución inicial: Una planilla técnica tradicional. Botones de "+" y "−" para fundamentos básicos como puntos, aces, bloqueos y errores.
  • Experiencia (UX): Curva de aprendizaje casi nula. Altamente intuitiva para cualquier usuario — si sabés leer una tabla, sabés usarla.
  • El límite real: Inviable para el ritmo frenético del vóley en vivo. Falta contexto espacial: el scouter piensa en zonas y jugadores en cancha, no en filas de una planilla.
  • Veredicto: Cumple el requisito a nivel de código, pero falla operativamente bajo presión de partido.
FASE 2

6:00 – 9:00

Salto Espacial

Mapeo Mental Directo

  • El salto conceptual: Pasamos de leer una lista de nombres a tocar zonas de una cancha en vivo. El analista asocia mentalmente al jugador con su posición real en el campo.
  • El nuevo cuello de botella: La distancia física que recorre el mouse entre seleccionar un jugador (izquierda) y clickear la acción (derecha) consume fracciones de segundo críticas en cada rally.
  • Evaluación UX: Demasiado "aire desperdiciado" visualmente. La UX mejora en comprensión y mapeo mental, pero no alcanza el límite de velocidad que exige el scouting de alto rendimiento.
FASE 3

9:00 – 13:00

Herramienta Pro

Eficiencia Operativa Máxima

  • Dashboard denso y full-width: Implementamos símbolos internacionales estandarizados de scouting — #, +, /, −, = — organizados en una grilla por tipo de acción: recepción, contraataque, bloqueo y defensa.
  • Carga cognitiva altísima: La interfaz es intencionalmente compleja para el novato, pero se convierte en la herramienta definitiva para el analista profesional que ya domina el dominio.
  • Filosofía UX: Minimizar el movimiento del cursor y maximizar el uso de atajos de teclado. La UX prioriza performance sobre simplicidad visual — un clic por acción, todo visible de un vistazo.

La lección · 13:00 – 14:00

La Paradoja UI vs UX

El Usuario Manda

El MVP era funcional y estético, pero el profesional en la tribuna dictó la necesidad de escalar la interfaz. El usuario final es quien define qué es "buen diseño".

Carga Cognitiva

A veces, "difícil de aprender" es el costo necesario para lograr que un sistema sea extremadamente rápido de operar bajo presión.

Falso Minimalismo

No reduzcas la complejidad visual si esto obliga a tu usuario experto a dar más clics bajo situaciones de alta presión.

Conclusiones · 14:00 – 15:00

Construir en público

No teoría de manual — el barro real de iterar un producto en producción, con decisiones difíciles entre UI atractiva y UX eficiente.

Tres iteraciones, tres lecciones

Tabular → Espacial → Pro. Cada fase resolvió un problema y creó otro. La iteración no es fracaso, es el proceso.

UI atractiva vs. UX eficiente

A veces ganan los botones feos. La interfaz "fea" puede ser la mejor experiencia de usuario si el dominio lo exige.

Escalar con el usuario

La UI debe escalar en complejidad junto con la expertise del operador. No hay que tenerle miedo a saturar la pantalla.

El mejor diseño no es el más bonito. Es el que deja al usuario experto trabajar más rápido.
